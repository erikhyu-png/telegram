# Página de tutorial — Telegram

Página estática responsiva inspirada na referência enviada.

## Personalizar o botão

Abra `script.js` e substitua:

```js
const TELEGRAM_URL = "https://t.me/SEU_CANAL";
```

pelo endereço real do seu canal, grupo ou bot do Telegram.

## Executar localmente

Basta abrir `index.html` no navegador. Para publicar, envie os arquivos para GitHub Pages, Netlify ou Vercel.

## Arquivos

- `index.html` — estrutura da página
- `styles.css` — visual e responsividade
- `script.js` — destino do botão
